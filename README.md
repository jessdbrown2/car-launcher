# car-launcher

Custom launcher for a QC4250 car stereo (Android 15, 1280×720).

- `inspector/` – read-only diagnostic app. Download: https://github.com/jessdbrown2/car-launcher/releases/download/inspector/inspector.apk
- `launcher/` – the home screen. Download: https://github.com/jessdbrown2/car-launcher/releases/download/launcher/launcher.apk
